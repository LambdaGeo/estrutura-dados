    Disciplina: Estrutura de Dados¶

    Bem-vindos à disciplina de Estrutura de Dados! Esta página é o hub central para o cronograma, materiais de aula, listas de exercícios e laboratórios.

    🎯 Objetivos da Disciplina¶

    Ao final desta disciplina, você será capaz de compreender, implementar e analisar as principais estruturas de dados utilizadas na computação. O objetivo é desenvolver a base necessária para a criação de algoritmos eficientes e a resolução de problemas complexos, utilizando a linguagem C como ferramenta principal.

    📚 Ementa¶

    • Recursividade
    • Tipos Abstratos de Dados (TAD)
    • Estruturas de dados básicas: listas lineares (pilhas, filas, listas encadeadas)
    • Árvores e aplicações
    • Árvores binárias: Árvore de Busca (BST), Árvores Balanceadas (AVL) e Heaps
    • Algoritmos de ordenação
    • Noções de complexidade de algoritmos
